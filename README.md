# Java Constructors, Inheritance, and Static Practice
This repository contains Java exercises focused on constructors, inheritance, and static members in object-oriented programming.

## Concepts Covered
- Constructors
- Inheritance
- Static variables and methods
- Classes and objects
- Method overriding
- Object-Oriented Programming (OOP)
- Code organization and reuse

## Tools Used
- Java
- IntelliJ IDEA

## Purpose
To practice key object-oriented programming concepts including constructors, inheritance relationships, and static members in Java.

Constructors are used to initialize objects when they are created. :contentReference[oaicite:0]{index=0}  

Inheritance allows one class to reuse properties and methods from another class, improving code organization and reducing repetition. :contentReference[oaicite:1]{index=1}  

Static variables and methods belong to the class rather than individual objects, allowing shared behavior across instances. :contentReference[oaicite:2]{index=2}  

This project helped strengthen understanding of class relationships and how reusable code can be designed using OOP principles.
